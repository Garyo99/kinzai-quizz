# きんざい学習室（公開用ファイル）

公開用のCSS・JavaScript・問題データを格納しています。サイトの入口は1階層上の `index.html` です。元の問題HTMLは参照しません。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選択し、対象ブランチのルート `/` を指定します。

- `../index.html`: 学習画面
- `styles.css`: スマートフォン・PC対応スタイル
- `app.js`: 出題、判定、履歴、復習機能
- `questions.js`: 整理済み問題データ
